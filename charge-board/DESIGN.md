# MAGFIELD HUB — M5Stack制御 10ch充電ボード 設計メモ

磁場可視化ノード（`../kicad/`、ノード基板v2 = JST PH 4pin仕様）の充電・書き込みハブ。
旧STM32ドック（`../kicad-dock/`）の後継で、頭脳は持たず、制御は Port A (Grove/I2C) で
接続した M5Stack が担う。チャンネル回路のレシピはドック設計を踏襲。

**状態: 100×96mm 版（2026-10-30 レイアウト変更＋仕上げ配線、同日に4層化して
プレーン接続化）。未接続は 23→**1項目**（U2.21 VCC のみ、下記「検証結果」に
理由と対処を明記）まで削減。DRC エラーは CH6_STAT ビア1箇所の4件のみ
（クリアランス 0.175mm／ホール 0.20mm、製造可能水準だがルール未達）。
U2.21 は改版か組立時のジャンパ配線で対処すること。それ以外は製造可能水準。**

## 基板仕様

- **100 × 96 mm**（2026-10-30 に 118×58 から変更、JLCPCB 最安サイズ帯 ≤100×100 に収納）、
  **4層**、1.6mm想定、JLCPCB標準ルール（クリアランス 0.15mm）
  - 層構成: **F.Cu 信号 / In1.Cu = GND 全面プレーン / In2.Cu = 電源プレーン
    （5V_CHG と 5V_LOG に分割）/ B.Cu 信号**
  - 当初はコスト優先で2層に留めたが、2層では GND/電源ポケットが23項目
    未接続のまま解消できなかったため、2026-10-30 のユーザー判断で本基板のみ
    4層化した（ノード基板は2層のまま）。PROG 24kΩ ≈ 41.7mA の仕様は不変。
- 小型化方針: ノードコネクタは11.35mmピッチ一列では約114mm必要なため、上辺に5個
  （J1〜J5）・下辺に5個（J6〜J10、180°回転）の2列配置に変更。各チャンネルの部品は
  コネクタに隣接するブロックに集約し、制御ICは基板中央の帯（y≈40〜58）に集約して
  信号引き回しを短縮した。
- ゾーン（すべて充填済みで保存）:
  - GND: F.Cu / B.Cu 全面（優先度0）＋ **In1.Cu 全面プレーン（優先度0）**
  - 5V_CHG: B.Cu の上チャンネル領域（y 8.5〜41）＋下チャンネル領域（y 57.5〜88.5）
    ＋左端スパイン（x 2〜16、USB-C/SJ1/C90/C91用、優先度10）
  - 5V_LOG: F.Cu の中央帯（y 31〜61.5、優先度10）— プルアップ抵抗群と制御ICの直上に給電
  - 5V_LOG: B.Cu の中央帯（x 18〜98、y 42〜56.5、優先度10）— 制御ICの直下に給電
    — 制御IC群の直下に給電し、F帯とはビアで接続
  - **In2.Cu 電源プレーン（4層化で追加）**: 5V_CHG = 上/下チャンネル帯
    （y 8.5〜41 / 57.5〜88.5）＋左スパイン（x 2〜16、y 40〜57.5、優先度10）、
    5V_LOG = 中央帯（y 31〜61.5、優先度20で重なり部を優先）。両ネットは
    プレーン上でも分離を維持。浮いていた GND/5V ポケットはビアで各プレーンへ接続した。

## アーキテクチャ

```
M5Stack ──Port A (Grove, I2C 3.3V)── レベルシフト ── I2C (5V) ─┬─ TCA9535 #1 (0x20)
                                                                ├─ TCA9535 #2 (0x21)
                                                                └─ ADS1115 (0x48)
USB-C 5V ── 5V_CHG プレーン ── 10ch充電チャンネル ── JST PH ── ノード
                    └── SJ1（ソルダージャンパ）── 5V_LOG ── ロジック全般
```

- 本基板にメインMCUは無い。全ての制御・計測はM5Stack上のプログラムが行う。
- 充電電力（10ch合計 約400mA）は Port A の5Vに依存せず **USB-C入力** から取る
  （Port A の5V供給能力はM5Stackの機種依存のため）。
- ロジック電源 5V_LOG は SJ1（3パッド・ソルダージャンパ）で選択:
  **デフォルト = 5V_CHG側（USB-C）**、代替 = Grove 5V (GRV_5V)。
  ジャンパ未接続（オープン）だとロジックは無電源になるので、必ずどちらかにブリッジする。
- I2Cレベルシフト: M5Stack Port A は 3.3V ロジック（5Vトレラントでない）ため、
  BSS138 ×2 の定番シフタを入れた。LV側プルアップ(10kΩ)用の 3.3V は
  XC6206P332MR (U91) で 5V_LOG から生成（このLDOの負荷はプルアップのみ）。
  HV側プルアップは 4.7kΩ → 5V_LOG。

## チャンネル回路（×10、ドック設計と同一レシピ）

部品番号は ch n に対して: 受け Jn (J1〜J10)、充電IC U(10+n)、PMOS Q(10+n)、
NMOS Q(20+n)、LED Dn、抵抗は R(100+(n−1)×10 + k) の規則（下表）。

| 役割 | 部品 | 値/型番 | 接続 |
|---|---|---|---|
| ノード接続 | J1〜J10 | JST B4B-PH-K-S | 1=GND, 2=VBAT, 3=UPDI, 4=ID/NC（ノードv2と一致） |
| 充電IC | U11〜U20 | MCP73831T-2ACI/OT (SOT-23-5) | 1=STAT, 2=VSS, 3=VBAT, 4=VDD(5V_CHG), 5=PROG |
| PROG抵抗 | R+1 | 24kΩ | I = 1000/Rprog(kΩ) ≈ 41.7mA ≒ LIR2032の1C（24.9kはBasicでないため24kに変更） |
| 入力容量 | C(50+n) | 4.7µF | 5V_CHG−GND |
| 電池側容量 | C(70+n) | 4.7µF | CHn_BAT−GND |
| カットオフ PMOS | Q(10+n) | AO3401A | S=充電IC側(CHn_CHG), D=ノード側(CHn_BAT) |
| ゲートプルアップ | R+2 | 100kΩ | CHn_BAT − CHn_GATE |
| ゲート駆動 NMOS | Q(20+n) | 2N7002 | ゲート=CHn_EN |
| ENプルアップ | R+3 | 100kΩ | 5V_LOG − CHn_EN |
| STATプルアップ | R+4 | 47kΩ | 5V_LOG − CHn_STAT |
| 状態LED抵抗 | R+5 | 1kΩ | 5V_CHG − LEDアノード |
| 状態LED | D1〜D10 | 0603 赤 | カソード=CHn_STAT（STATがLow=充電中に点灯） |
| VBAT分圧 上 | R+6 | 330kΩ | CHn_BAT − CHn_VSENSE |
| VBAT分圧 下 | R+7 | 330kΩ | CHn_VSENSE − GND |

### カットオフの動作（デフォルトON）

- CHn_EN は 100kΩ で 5V_LOG にプルアップされているため、**電源投入時・エクスパンダ
  未初期化時（TCA9535は電源投入時 全ポート入力=Hi-Z）でも EN=High → NMOS ON →
  PMOS ON → 充電が進む**。過充電側の安全は充電ICの4.2V終止が担保する。
- 止めるときはホストが該当ENを出力・Lowにする（「CHn_ENは充電許可、アクティブHigh」）。

### STATの読み取り（デジタル）

MCP73831 の STAT はオープンドレイン/3ステート。47kΩプルアップでエクスパンダの
入力として読む:

| STAT | 読み | 意味 |
|---|---|---|
| Low | 0 | 充電中 |
| Hi-Z → プルアップで High | 1 | 充電完了 または ノード未接続/異常（VBAT計測で判別可能） |

| デバイス | 型番 | I2Cアドレス | 役割 |
|---|---|---|---|
| U2 TCA9535RTWR #1 | WQFN-24 | **0x20**（A2=A1=A0=GND） | EN1–8（出力）、STAT1–8（入力） |
| U3 TCA9535RTWR #2 | WQFN-24 | **0x21**（A0=5V_LOG, A1=A2=GND） | EN9–10、MUX選択、UPDI有効化、STAT9–10 |

## VBAT計測（74HC4067 #1 + ADS1115）

- 各チャンネルの CHn_BAT を 330k/330k で 1/2 に分圧し、U5 (74HC4067) の
  Y0–Y9 に入力。共通端子 Z → ADS1115 AIN0（100nF の平滑容量 C99 付き）。
- 換算: **VBAT = 2 × V(AIN0)**。ADS1115 は PGA = ±4.096V 設定を推奨
  （LSB = 125µV → VBAT分解能 0.25mV）。
- 分圧抵抗はノード接続中だけ電池から約 4.2V/660kΩ ≈ **6.4µA** を消費する。
  充電電流40mAに対して無視でき、計測ポーズ（秒オーダー）でも問題にならない。
- マルチプレクサ選択表（両MUX共通、UPDI側も同じチャンネルが選ばれる）:

| S3 S2 S1 S0 | 選択チャンネル | | S3 S2 S1 S0 | 選択チャンネル |
|---|---|---|---|---|
| 0 0 0 0 | ch1 (Y0) | | 0 1 0 1 | ch6 (Y5) |
| 0 0 0 1 | ch2 (Y1) | | 0 1 1 0 | ch7 (Y6) |
| 0 0 1 0 | ch3 (Y2) | | 0 1 1 1 | ch8 (Y7) |
| 0 0 1 1 | ch4 (Y3) | | 1 0 0 0 | ch9 (Y8) |
| 0 1 0 0 | ch5 (Y4) | | 1 0 0 1 | ch10 (Y9) |

  S=1010〜1111 は Y10–Y15（未接続）を指す。ホストは使わないこと。

## UPDIルーティング（74HC4067 #2）

- 外部のUPDIソース（M5Stackの別ポートやUSB-UARTアダプタ等、本基板の範囲外）を
  **J12 UPDI_IN**（JST B3B-PH-K-S、3pin: 1=UPDI_SRC, 2=GND, 3=NC/将来の対象電源用）に接続する。
- U6 の Z = UPDI_SRC、Y0–Y9 = 各チャンネルの UPDI（ノードコネクタ pin3）。
  選択は U5 と共通の MUX_S0–S3（上表）。
- U6 の /E は UPDI_EN（U3 P06、アクティブLow）: ホストが Low を書いたときだけ
  選択中チャンネルに UPDI がつながる。それ以外は全チャンネル絶縁。
- 注意: 74HC4067 のオン抵抗（約80Ω）は SerialUPDI 系の抵抗ネットワークと
  直列に入る。書き込み側の抵抗値は実機で調整すること（TODO参照）。

## ホスト（M5Stack）プログラムの想定動作

初期化:
1. U2/U3 の Configuration レジスタで EN・MUX_S・UPDI_EN のピンを出力に設定
   （U2: Port0=出力, Port1=入力。U3: Port0=出力, Port1=入力）。
   出力ラッチは初期化前に「EN=全High（充電許可）、UPDI_EN=High（無効）」を
   先に書いてから出力有効化すると、初期化中の中断がない。
2. ADS1115 を単発/連続変換、PGA ±4.096V、AIN0 測定に設定。

充電ループ（80〜90%カットオフ）:
1. STAT をポーリング。Low のチャンネルが充電中。
2. 定期的に（例: 各ch 数十秒おき）**計測ポーズ**: 該当chの EN を Low（充電停止）
   → MUX_S をそのchに合わせる → 数百ms待って電池電圧が落ち着くのを待つ
   → ADS1115 で読む → VBAT = 2×読み値 → EN を High に戻して充電再開。
   充電中の端子電圧は電流で高めに出るため、この「止めて測る」が必須。
3. 目標電圧（LIR2032 で 80〜90% ≒ 約3.95〜4.05V、実測で詰める）に達したら
   EN を Low のままにしてそのchを終了。STAT が High になれば充電IC側の
   満充電終止（4.2V）に到達した合図としても使える。
4. STAT=High かつ VBAT が低い場合はノード未接続/異常と判断できる。

UPDI書き込み:
1. 対象chの EN はどちらでもよい（ノード側は自電池で動作する前提）。
2. MUX_S に対象ch番号を設定 → UPDI_EN を Low → 外部UPDIソースから書き込み
   → 終了後 UPDI_EN を High に戻す。同時に書けるのは1台のみ。
