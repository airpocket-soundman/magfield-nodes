# 充電ボード（設計中）

ノード基板10台分の充電・監視・書き込みをまとめるボードです。現在KiCadで設計中のため、このフォルダはプレースホルダです。設計が完了したら、ここにKiCadファイル一式と DESIGN.md を追加します。

## 構成（予定）

- ホスト接続: M5Stack の Port A（Grove / I2C）。ボード自体にマイコンは載せない
- 充電チャンネル ×10: MCP73831（PROG抵抗で約40mA = LIR2032の1C）、チャンネルごとのカットオフ用MOSFETとステータスLED
- 制御・監視: TCA9535（I2C GPIOエクスパンダ）×2 でカットオフ制御とSTAT読み取り、74HC4067（アナログマルチプレクサ）+ ADS1115（I2C ADC）で全チャンネルの電池電圧を読み取り
  - 「充電を一瞬止めてから電圧を測る」ことで、80〜90%充電でのカットオフを電圧ベースで判定する
- 書き込み: UPDI入力を同様に切り替えて、選択したチャンネルのノードへ書き込み信号を送る
- 電源: 充電用5VはボードのUSB-C入力から（10ch合計約400mAのため、Port Aの5Vには頼らない）
- ノード接続: JST PH 4ピン ×10（1=GND / 2=VBAT充電 / 3=UPDI / 4=ID予備）— ノード基板側と同一の割り当て
